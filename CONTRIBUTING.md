# Contributing

Thanks for helping with AnixOps Control.

1. **Sign the CLA once.** Read [`CLA.md`](CLA.md) and add your line to
   [`.github/cla-signatures.txt`](.github/cla-signatures.txt) in your first
   pull request. The "CLA" check verifies it.
2. **Follow the repository rules.** [`AGENTS.md`](AGENTS.md) applies to humans
   and coding agents alike: branch from `main`, open a pull request, add a
   changelog fragment (`changelog.d/README.md`), and let CI verify the change.
3. **Write your own code.** Do not paste code or example configurations from
   other projects. If a change needs third-party work, say so in the pull
   request with its source and license.
4. **Know what the community edition covers.** Payment, orders, coupons and
   invite commission live in the commercial edition and are not accepted here
   ([`LICENSING.md`](LICENSING.md)).

Security issues: do not open a public issue; write to contact@anixops.com.
