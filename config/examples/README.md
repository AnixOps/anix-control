# Config Examples

This directory holds sample inputs and reference files that should not live at the repository root.

Files:
- `local_test.yaml`: small local subtest input
- `test_nodes.yaml`: richer sample node/subscription input generated by `cmd/subtest`
- `forwarding-acceptance.yaml.example`: fail-closed evidence template for the
  signed `nftables-forward` production rollout; copy it to the ignored
  `config/forwarding-acceptance.yaml` only for a real deployment rehearsal

Typical usage:

```powershell
go run .\cmd\subtest\main.go sub .\config\examples\local_test.yaml v2ray
go run .\cmd\subtest\main.go sub .\config\examples\test_nodes.yaml clash
```
