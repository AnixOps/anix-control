AnixOps Control {{ .Chart.AppVersion }} is starting ({{ include "anix-control.image" . }}).

Readiness:
  kubectl -n {{ .Release.Namespace }} rollout status deployment/{{ include "anix-control.fullname" . }}

First administrator: on a fresh database, print the one-time link that creates it (it works once, for
24 hours; running the command again replaces it), then open it in a browser:
  kubectl -n {{ .Release.Namespace }} exec deployment/{{ include "anix-control.fullname" . }} -c control -- /app/anix-control admin claim-link

The web app and the API (one port):
  kubectl -n {{ .Release.Namespace }} port-forward svc/{{ include "anix-control.fullname" . }} 8080:{{ .Values.service.httpPort }}
