# 组网：地区、地址分配与入网凭据

状态：第一阶段已实现（地区、地址、宿主组、内网域名名单、地区变更审批）；入网凭据、设备接口与只读上报在第二阶段，经 Agent 下发组网配置在第三阶段。编号沿用项目需求表（R1–R35）。组网模块在内核中实现；本页是面板负责的部分。地区控制面中继与发布文件缓存（R33、R34）见区域中继的设计文档 `docs/design/region-relay/`。

## 地区（R18、R20、R27、R30）

- 首次使用时创建默认四个地区：中国大陆 `cn`、亚太 `ap`（日本、香港、台湾等不拆分）、欧洲 `eu`、北美 `na`；管理员可增删。
- 每个地区是独立网络：生成的网络名（`mesh-<代码>-<12 位十六进制>`）、网络密钥（以 Control 的密钥加密密钥封存，首个成员入区时生成，任何接口都不返回明文）、私有 IPv4 虚拟子网（/8 至 /24）。
- 地区网络一律启用前向保密，接口中 `security` 恒为 `forward_secrecy`。
- 子网互不重叠，也不与宿主组超网和保留网段（如迁移期间现有网络的虚拟子网）重叠。
- 子网划分为服务器段与设备地址池，两者不重叠；成员配置的前缀长度为地区子网的长度。
- 告警：边界节点不足两台（`few_border_nodes`）、边界节点缺少探测地址（`border_without_probe_address`）、设备地址池剩余不足一成（`device_pool_low`）。
- 地区代码不可修改；子网只在地区没有成员时可改；地区有成员或有待审批的迁入申请时不能删除。

## 成员与地址（R29）

- 角色：边界节点 `border`、网关 `gateway`、服务器 `server`、设备 `device`。
- 边界节点、网关、服务器使用固定地址：管理员指定（地区子网内、设备地址池外），或取服务器段最低空闲地址。地址与节点身份绑定。
- 设备默认使用地址池：取池内最低空闲地址，按设备保持不变。地址连续 30 天未使用才可被下一台需要地址的设备取用，取用时原设备的地址清空；只要池内还有空闲地址就不回收。
- 子网的首地址与末地址不分配。数据库对（地区，地址）有唯一索引。
- 主机名为一个 DNS 标签（小写字母、数字与中间连字符），在地区内与设备名一起唯一；内网域名为 `主机名.地区代码.后缀`，后缀默认 `mesh.internal`，可配置。
- 一个 Agent 节点（`proxy-<id>` 或 `forward-<id>`）最多对应一个成员。

## 宿主组与设备命名（R21、R25、R26）

- 宿主组由一台网关和可选的一台备用网关代表入网，两者同属一个地区；宿主组随网关所在地区。
- 组地址段取自宿主组超网（默认 `10.127.0.0/16`，每组 `/24`），不与任何地区子网重叠；可指定或自动取第一个空闲段，创建后不变。
- 组内虚拟机和网关局域网内的设备只能手动命名，不做网络扫描。虚拟机地址须在组地址段内；局域网设备地址须为私有地址且不在地区子网与宿主组超网内。名称由网关发布。
- 网关迁区时，组内另一台网关须已在目标地区；网关发布的名称随网关迁移。宿主组的网关不能直接删除。

## 地区变更（R20、R24）

- 首次入区自动选区（第二阶段的入区接口）；之后的变更由成员申请，管理员批准或拒绝；管理员也可直接迁移。
- 批准或迁移时成员获得目标地区的新地址（固定地址可指定，否则自动分配），记录新旧地址；旧地址上的连接会断开。
- 每个成员最多一个待审批申请；管理员直接迁移到申请的地区即批准该申请，其他待审批申请一并拒绝。

## 管理接口（第一阶段）

全部在 `/api/v5/mesh` 下，需管理员身份，写操作记入操作日志。

| 方法与路径 | 用途 |
|---|---|
| `GET /mesh` | 设置、地区（含计数与告警）、宿主组、待审批数 |
| `PUT /mesh/settings` | 域名后缀、宿主组超网与前缀、保留网段 |
| `POST /mesh/regions`、`PUT`/`DELETE /mesh/regions/:id` | 地区 |
| `GET`/`POST /mesh/members`、`PUT`/`DELETE /mesh/members/:id` | 成员与地址 |
| `POST /mesh/members/:id/move` | 管理员迁移 |
| `GET`/`POST /mesh/host-groups`、`PUT`/`DELETE /mesh/host-groups/:id` | 宿主组 |
| `GET`/`POST /mesh/device-names`、`PUT`/`DELETE /mesh/device-names/:id` | 设备命名 |
| `GET /mesh/names` | 内网域名名单（含重名标记） |
| `GET /mesh/region-changes`、`POST /mesh/region-changes/:id/approve`、`.../reject` | 地区变更 |

## 入网凭据与只读上报（R31，第二阶段）

- 面板为节点签发一次性入网凭据（Agent 节点经 Agent 下发，无 Agent 节点经安装命令使用）。凭据使用一次后作废，节点随后以自己的设备密钥签名请求。
- 凭据内容：面板地址、凭据编号与一次性密钥、有效期、目录入口（各地区边界节点的探测地址与公钥），由面板签名；不含任何地区的网络密钥。
- 设备接口：入网（以凭据换取设备登记）、入区（提交测得的延迟，面板分配地址并返回网络名、密钥与地址）、地区变更申请、只读上报（在线状态与延迟）。上报只回状态码，不下发指令；凭据或设备撤销后拒绝。
- 节点告警：地址冲突、「地址未受管」、控制面失联。

## 界面

网络 → 组网（`/admin/mesh`）：地区（子网、服务器段、设备地址池、边界节点数、告警）、成员（角色、地址与方式、内网域名、迁移）、宿主组与设备命名、内网域名名单、变更申请审批、设置。
